## ▶️ How to Run

**Static pages (HTML / CSS / JS)**

1. Open the folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` → **Open with Live Server**.

**Node / Express projects**

```bash
cd 06-nodejs-and-express/<project-name>
npm install
node index.js        # or: npm start / nodemon
```

**React / Next.js projects**

```bash
cd 10-react/<project-name>     # or 11-nextjs/<project-name>
npm install
npm run dev
```

Then open `http://localhost:3000` (or the port shown in your terminal).

> Projects that use MongoDB need a local MongoDB instance or a MongoDB Atlas connection string. Put it in a `.env` file and never commit it.
